# 01. EC2 인스턴스 생성

Terraform으로 OpenClaw용 EC2를 프로비저닝하는 과정을 기록한다.

## 인프라 구성

| 항목 | 값 |
|------|-----|
| 리전 | ap-northeast-2 (서울) |
| 인스턴스 | t3.medium |
| OS | Ubuntu 22.04 LTS |
| 디스크 | 30GB gp3 |
| 보안그룹 | SSH(22), Gateway(18789), HTTPS(443) |
| Elastic IP | 할당됨 |

## 사전 준비

1. AWS CLI 설정 완료 (`aws configure`)
2. Terraform 설치 (`>= 1.0`)
3. EC2 키 페어 준비

## 실행 순서

### 1. 변수 파일 생성

```bash
cd terraform/
cp terraform.tfvars.example terraform.tfvars
```

`terraform.tfvars`를 열어 실제 값을 입력한다:

```hcl
key_name = "내-키페어-이름"
my_ip    = "내-공인-IP"
```

내 공인 IP는 다음으로 확인:

```bash
curl -s ifconfig.me
```

### 2. Terraform 초기화

```bash
terraform init
```

### 3. 실행 계획 확인

```bash
terraform plan
```

생성될 리소스:
- `aws_instance.openclaw` — EC2 인스턴스
- `aws_security_group.openclaw` — 보안 그룹
- `aws_eip.openclaw` — Elastic IP

### 4. 인프라 생성

```bash
terraform apply
```

`yes`를 입력하면 리소스가 생성된다.

### 5. 접속 확인

apply 완료 후 출력되는 `ssh_command`로 접속:

```bash
ssh -i ~/.ssh/내-키페어.pem ubuntu@<출력된-IP>
```

## 정리 (삭제)

더 이상 필요 없을 때:

```bash
terraform destroy
```
