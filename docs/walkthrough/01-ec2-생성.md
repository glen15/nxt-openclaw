# 01. EC2 인스턴스 생성

Terraform으로 OpenClaw용 EC2를 프로비저닝하는 과정을 기록한다.

## 인프라 구성

| 항목 | 값 |
|------|-----|
| 리전 | ap-northeast-2 (서울) |
| 인스턴스 | t3.medium |
| OS | Ubuntu 22.04 LTS |
| 디스크 | 30GB gp3 |
| 보안그룹 | SSH(22), Gateway(18789), HTTPS(443) |
| Elastic IP | 할당됨 |

## 사전 준비

1. **AWS CLI 설정 완료**: `aws configure`로 Access Key, Secret Key, 리전 설정
2. **Terraform 설치**: 버전 1.0 이상 ([설치 가이드](https://developer.hashicorp.com/terraform/install))
3. **EC2 키 페어 준비**: AWS 콘솔 > EC2 > 키 페어에서 생성 후 `.pem` 파일 다운로드

```bash
# 다운로드한 키 파일 권한 설정 (필수)
chmod 400 ~/.ssh/<키페어-이름>.pem
```

## 실행 순서

### 1. 변수 파일 생성

```bash
cd terraform/
cp terraform.tfvars.example terraform.tfvars
```

`terraform.tfvars`를 열어 실제 값을 입력한다:

```hcl
key_name = "내-키페어-이름"
my_ip    = "내-공인-IP"
```

내 공인 IP는 다음으로 확인:

```bash
curl -s ifconfig.me
```

### 2. Terraform 초기화

```bash
terraform init
```

### 3. 실행 계획 확인

```bash
terraform plan
```

생성될 리소스:
- `aws_instance.openclaw` — EC2 인스턴스
- `aws_security_group.openclaw` — 보안 그룹
- `aws_eip.openclaw` — Elastic IP

### 4. 인프라 생성

```bash
terraform apply
```

`yes`를 입력하면 리소스가 생성된다.

### 5. 접속 확인

apply 완료 후 아래와 같은 출력이 표시된다:

```
Apply complete! Resources: 3 added, 0 changed, 0 destroyed.

Outputs:

instance_id = "i-0abc1234def56789"
public_dns  = "ec2-12-34-56-78.ap-northeast-2.compute.amazonaws.com"
public_ip   = "12.34.56.78"
ssh_command = "ssh -i ~/.ssh/<키페어-이름>.pem ubuntu@12.34.56.78"
```

출력된 `ssh_command`로 접속:

```bash
ssh -i ~/.ssh/<키페어-이름>.pem ubuntu@<출력된-IP>
```

## 커스터마이징

`terraform/variables.tf`에서 기본값을 변경할 수 있다:

| 변수 | 기본값 | 변경 예시 |
|------|--------|----------|
| `aws_region` | `ap-northeast-2` (서울) | `us-east-1` (버지니아) — AI API 지연 감소 |
| `instance_type` | `t3.medium` | `t3.small` — 비용 절약, 최소 사양 |

변경은 `terraform.tfvars`에서 덮어쓴다:

```hcl
instance_type = "t3.small"
```

## 다음 단계

Terraform이 EC2를 생성하면서 **OpenClaw을 자동 설치**한다 (`user_data` 스크립트로 `--no-onboard` 모드 설치).

SSH 접속 후 설치가 완료되었는지 확인:

```bash
# EC2에서 실행
openclaw --version
```

버전이 출력되면 설치 성공이다. [02-openclaw-설치.md](./02-openclaw-설치.md)의 **2단계: 온보딩 위자드**부터 진행한다.

> **참고**: `openclaw: command not found`가 표시되면 설치가 아직 진행 중이거나 실패한 것이다. 1~2분 기다린 후 재시도하고, 그래도 안 되면 02의 1단계(수동 설치)를 따른다.
