# 08. 운영 및 관리

OpenClaw를 안정적으로 운영하기 위한 관리 방법을 설명합니다.

## 서비스 상태 확인

### Gateway 상태

```bash
# 상태 확인
openclaw gateway status

# 전체 시스템 진단
openclaw doctor
```

`openclaw doctor`는 다음을 확인합니다:
- Gateway 연결
- AI 모델 인증
- 채널 상태
- 보안 설정
- 디스크 공간

### 실시간 로그 모니터링

```bash
# 실시간 로그 보기
openclaw logs --follow

# 특정 채널 로그만 보기
openclaw logs --follow --filter telegram
```

## 업데이트

### OpenClaw 업데이트

```bash
# 최신 안정 버전으로 업데이트
npm update -g openclaw@latest

# 업데이트 후 진단 실행
openclaw doctor
```

또는 OpenClaw 내장 업데이트 명령:
```bash
openclaw update --channel stable
```

### Node.js 업데이트

```bash
# 최신 Node.js 22 LTS 설치
nvm install 22 --reinstall-packages-from=current
nvm alias default 22
```

### 시스템 업데이트

```bash
sudo apt update && sudo apt upgrade -y
```

## 백업

### 무엇을 백업해야 하는가?

| 경로 | 내용 | 중요도 |
|------|------|--------|
| `~/.openclaw/config.json5` | 설정 파일 | 매우 높음 |
| `~/.openclaw/workspace/` | 작업 공간 (파일, 스킬) | 높음 |
| `~/.openclaw/agents/` | 에이전트 세션, 메모리 | 높음 |

### 수동 백업

```bash
# 전체 OpenClaw 데이터 백업
tar czf ~/openclaw-backup-$(date +%Y%m%d).tar.gz ~/.openclaw/

# S3에 업로드 (AWS CLI 설정 필요)
aws s3 cp ~/openclaw-backup-$(date +%Y%m%d).tar.gz s3://my-backup-bucket/
```

### 자동 백업 (cron)

```bash
# crontab 편집
crontab -e
```

다음 줄을 추가 (매일 새벽 3시에 백업):
```
0 3 * * * tar czf /home/ubuntu/backups/openclaw-$(date +\%Y\%m\%d).tar.gz /home/ubuntu/.openclaw/ 2>/dev/null
```

백업 폴더 생성:
```bash
mkdir -p ~/backups
```

### 백업 복원

```bash
# 기존 설정 백업 (안전을 위해)
mv ~/.openclaw ~/.openclaw.old

# 백업에서 복원
tar xzf ~/openclaw-backup-20260214.tar.gz -C /

# Gateway 재시작
openclaw gateway restart
```

## 모니터링

### 리소스 사용량 확인

```bash
# 메모리 사용량
free -h

# 디스크 사용량
df -h /
du -sh ~/.openclaw/

# CPU 사용량
top -bn1 | head -20

# OpenClaw 프로세스 확인
ps aux | grep openclaw
```

### 디스크 정리

```bash
# 오래된 로그 정리
find ~/.openclaw/logs -name "*.log" -mtime +30 -delete

# npm 캐시 정리
npm cache clean --force
```

## Gateway 재시작 및 복구

### 정상 재시작

```bash
openclaw gateway restart
```

### Gateway가 응답하지 않을 때

```bash
# 프로세스 확인
ps aux | grep openclaw

# Gateway 프로세스 종료 후 재시작
openclaw gateway stop
openclaw gateway --port 18789 --verbose
```

### 서버 재부팅 후

데몬으로 설치했다면 자동으로 시작됩니다. 확인:

```bash
# systemd 서비스 확인
systemctl --user status openclaw-gateway

# 자동 시작 확인
systemctl --user is-enabled openclaw-gateway
```
