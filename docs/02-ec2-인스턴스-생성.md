# 02. AWS EC2 인스턴스 생성

이 장에서는 OpenClaw를 실행할 EC2 인스턴스를 생성합니다.

## 사전 준비

- AWS 계정이 있어야 합니다
- AWS 콘솔에 로그인할 수 있어야 합니다

> 아직 AWS 계정이 없다면: https://aws.amazon.com/ 에서 무료로 가입할 수 있습니다.

## Step 1: EC2 대시보드 접속

1. AWS 콘솔(https://console.aws.amazon.com/)에 로그인
2. 상단 검색창에 "EC2" 입력
3. **EC2** 서비스 클릭

> **리전 선택**: 오른쪽 상단에서 리전을 선택합니다. 한국에서 사용한다면 **Asia Pacific (Seoul) - ap-northeast-2**를 선택하세요.

## Step 2: 인스턴스 시작

1. EC2 대시보드에서 **"인스턴스 시작"** (Launch Instance) 버튼 클릭

### 이름 설정

- **이름**: `openclaw-server` (원하는 이름으로)

### AMI(운영체제) 선택

- **Ubuntu Server 22.04 LTS (HVM), SSD Volume Type** 선택
- **아키텍처**: 64-bit (x86)

> **왜 Ubuntu?**: OpenClaw 공식 문서에서 Ubuntu 22.04+를 권장합니다. 커뮤니티 자료도 Ubuntu 기준이 가장 많습니다.

### 인스턴스 유형 선택

| 유형 | vCPU | 메모리 | 용도 |
|------|------|--------|------|
| t3.small | 2 | 2 GB | 최소 사양 (기본 기능만) |
| **t3.medium** | **2** | **4 GB** | **권장 (브라우저 기능 포함)** |
| t3.large | 2 | 8 GB | 여유있는 사양 |

- **권장**: `t3.medium` 선택

### 키 페어 설정

1. **"새 키 페어 생성"** 클릭
2. **키 페어 이름**: `openclaw-key`
3. **키 페어 유형**: RSA
4. **프라이빗 키 파일 형식**:
   - macOS/Linux: `.pem`
   - Windows (PuTTY): `.ppk`
5. **"키 페어 생성"** 클릭 → 파일이 자동 다운로드됨

> **중요**: 다운로드된 키 파일은 안전한 곳에 보관하세요. 이 파일을 잃어버리면 서버에 접속할 수 없습니다!

### 네트워크 설정

**"편집"** 버튼을 클릭하고 다음과 같이 보안 그룹을 설정합니다:

#### 보안 그룹 규칙

| 유형 | 프로토콜 | 포트 | 소스 | 용도 |
|------|----------|------|------|------|
| SSH | TCP | 22 | 내 IP | SSH 접속 |
| 사용자 지정 TCP | TCP | 18789 | 내 IP | OpenClaw Gateway |
| HTTPS | TCP | 443 | 0.0.0.0/0 | 웹 접속 (선택) |

> **보안 팁**: "내 IP"를 선택하면 현재 접속 중인 IP에서만 접근 가능합니다. "0.0.0.0/0"은 어디서나 접근 가능하지만 보안상 주의가 필요합니다.

### 스토리지 설정

- **크기**: 30 GB (기본 8GB에서 변경)
- **볼륨 유형**: gp3

> OpenClaw 자체는 크지 않지만, Node.js, npm 패키지, 로그 등을 고려하면 30GB가 적당합니다.

### 인스턴스 시작

1. 설정을 확인한 후 **"인스턴스 시작"** 클릭
2. "인스턴스가 시작되었습니다" 메시지 확인

## Step 3: SSH로 서버 접속

인스턴스가 "실행 중" 상태가 되면 SSH로 접속합니다.

### 퍼블릭 IP 확인

1. EC2 대시보드 → 인스턴스 목록에서 생성한 인스턴스 클릭
2. **퍼블릭 IPv4 주소** 복사 (예: `3.34.xxx.xxx`)

### macOS / Linux에서 접속

```bash
# 키 파일 권한 설정 (처음 한 번만)
chmod 400 ~/Downloads/openclaw-key.pem

# SSH 접속
ssh -i ~/Downloads/openclaw-key.pem ubuntu@<퍼블릭-IP>
```

예시:
```bash
ssh -i ~/Downloads/openclaw-key.pem ubuntu@3.34.123.456
```

### Windows에서 접속

**방법 1: PowerShell**
```powershell
ssh -i C:\Users\<사용자>\Downloads\openclaw-key.pem ubuntu@<퍼블릭-IP>
```

**방법 2: PuTTY 사용**
1. PuTTY 실행
2. Host Name에 `ubuntu@<퍼블릭-IP>` 입력
3. Connection → SSH → Auth → Private key file에서 `.ppk` 파일 선택
4. Open 클릭

### 접속 성공 확인

```
Welcome to Ubuntu 22.04.x LTS (GNU/Linux 5.15.0-xxx-aws x86_64)
...
ubuntu@ip-172-31-xx-xx:~$
```

위와 같은 메시지가 보이면 성공입니다!

## Step 4: 탄력적 IP 할당 (권장)

기본 퍼블릭 IP는 인스턴스를 재시작하면 변경됩니다. 고정 IP가 필요하면 탄력적 IP를 할당합니다.

1. EC2 대시보드 → **탄력적 IP** → **탄력적 IP 주소 할당**
2. **할당** 클릭
3. 생성된 탄력적 IP 선택 → **작업** → **탄력적 IP 주소 연결**
4. 인스턴스에서 `openclaw-server` 선택 → **연결**

> **참고**: 탄력적 IP는 인스턴스에 연결되어 있는 동안은 무료입니다. 연결하지 않고 놔두면 소액 과금됩니다.
