# 03. 서버 환경 설정

EC2 인스턴스에 SSH로 접속한 상태에서 OpenClaw 실행에 필요한 환경을 설정합니다.

## Step 1: 시스템 업데이트

```bash
sudo apt update && sudo apt upgrade -y
```

> 이 명령은 Ubuntu의 모든 패키지를 최신 버전으로 업데이트합니다. 몇 분 걸릴 수 있습니다.

## Step 2: 필수 패키지 설치

```bash
sudo apt install -y git curl wget build-essential
```

| 패키지 | 용도 |
|--------|------|
| `git` | 소스 코드 관리 |
| `curl` | 파일 다운로드, API 호출 |
| `wget` | 파일 다운로드 |
| `build-essential` | C/C++ 컴파일러 (일부 npm 패키지에 필요) |

## Step 3: Node.js 22 설치

OpenClaw는 **Node.js 22 이상**이 필요합니다. nvm(Node Version Manager)을 사용해서 설치합니다.

### nvm 설치

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
```

설치 후 터미널을 새로고침합니다:

```bash
source ~/.bashrc
```

### Node.js 22 설치 및 기본값 설정

```bash
# Node.js 22 LTS 설치
nvm install 22

# 기본 버전으로 설정
nvm alias default 22

# 설치 확인
node --version   # v22.x.x 출력되어야 함
npm --version    # 10.x.x 출력되어야 함
```

## Step 4: 메모리 스왑 설정 (권장)

t3.medium은 4GB RAM입니다. 안정적 실행을 위해 스왑 메모리를 추가합니다.

```bash
# 2GB 스왑 파일 생성
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# 재부팅 후에도 유지되도록 설정
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

# 확인
free -h
```

출력 예시:
```
              total        used        free      shared  buff/cache   available
Mem:          3.8Gi       300Mi       2.8Gi       0.0Ki       700Mi       3.3Gi
Swap:         2.0Gi          0B       2.0Gi
```

## Step 5: 환경 확인

모든 설정이 완료되었는지 확인합니다:

```bash
# Node.js 버전 확인
node --version

# npm 버전 확인
npm --version

# git 버전 확인
git --version

# 메모리 확인
free -h

# 디스크 확인
df -h /
```

### 기대하는 결과

```
$ node --version
v22.x.x

$ npm --version
10.x.x

$ git --version
git version 2.x.x

$ free -h
              total        used        free
Mem:          3.8Gi       ...         ...
Swap:         2.0Gi       ...         ...

$ df -h /
Filesystem      Size  Used Avail Use%
/dev/xvda1       29G   5G   24G  18%
```

위와 비슷한 결과가 나오면 환경 설정이 완료된 것입니다!
