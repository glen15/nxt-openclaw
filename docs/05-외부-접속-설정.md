# 05. 외부 접속 설정

OpenClaw Gateway는 기본적으로 `127.0.0.1:18789`에서만 접속 가능합니다. 외부에서 접속하려면 추가 설정이 필요합니다.

3가지 방법 중 하나를 선택하세요:

| 방법 | 난이도 | 보안 | 추천 |
|------|--------|------|------|
| **A. Tailscale** | 쉬움 | 높음 | 개인 사용 |
| B. Nginx 리버스 프록시 | 중간 | 높음 | 공개 서비스 |
| C. SSH 터널 | 쉬움 | 높음 | 임시 접속 |

---

## 방법 A: Tailscale (가장 쉬움, 권장)

Tailscale은 VPN 서비스로, 설치만 하면 어디서나 안전하게 접속할 수 있습니다.

### Step 1: EC2에 Tailscale 설치

```bash
# Tailscale 설치
curl -fsSL https://tailscale.com/install.sh | sh

# Tailscale 시작 (인증 URL이 출력됨)
sudo tailscale up
```

출력되는 URL을 브라우저에서 열어 Tailscale 계정으로 로그인합니다.

> **Tailscale 계정이 없다면**: https://tailscale.com/ 에서 무료 계정을 만들 수 있습니다 (무료 플랜으로 100대까지 연결 가능).

### Step 2: 내 PC/폰에도 Tailscale 설치

- macOS: App Store에서 "Tailscale" 설치
- Windows: https://tailscale.com/download
- iOS/Android: 앱스토어에서 "Tailscale" 설치
- 동일한 Tailscale 계정으로 로그인

### Step 3: OpenClaw에 Tailscale 모드 설정

```bash
# Tailscale Serve 모드로 Gateway 시작
openclaw gateway --tailscale serve
```

또는 설정 파일에서:
```json
{
  "gateway": {
    "bind": "loopback",
    "tailscale": { "mode": "serve" }
  }
}
```

### Step 4: 접속 확인

같은 Tailscale 네트워크에 있는 기기에서:

```
https://<EC2의-tailscale-hostname>/
```

> Tailscale 호스트명은 `tailscale status` 명령으로 확인할 수 있습니다.

### Tailscale 모드 비교

| 모드 | 접속 범위 | 인증 |
|------|----------|------|
| `serve` | 같은 Tailscale 네트워크만 | Tailscale ID 자동 인증 |
| `funnel` | 인터넷 어디서나 | 비밀번호 필수 |

> **보안 팁**: 개인 사용이라면 `serve` 모드로 충분합니다. `funnel` 모드는 반드시 강력한 비밀번호를 설정하세요.

## 방법 B: Nginx 리버스 프록시 + HTTPS

도메인이 있고, 인터넷에서 직접 접속하고 싶을 때 사용합니다.

### Step 1: Nginx 설치

```bash
sudo apt install -y nginx
```

### Step 2: Certbot으로 SSL 인증서 발급

```bash
# Certbot 설치
sudo apt install -y certbot python3-certbot-nginx

# 인증서 발급 (도메인을 본인 것으로 변경)
sudo certbot --nginx -d your-domain.com
```

> **사전 조건**: 도메인의 DNS A 레코드가 EC2의 퍼블릭 IP를 가리키고 있어야 합니다.

### Step 3: Nginx 설정

```bash
sudo nano /etc/nginx/sites-available/openclaw
```

다음 내용을 입력합니다:

```nginx
server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:18789;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

```bash
# 설정 활성화
sudo ln -s /etc/nginx/sites-available/openclaw /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### Step 4: OpenClaw Gateway 인증 설정

외부 접속을 허용하므로 반드시 인증을 설정합니다:

```bash
# 비밀번호 설정
export OPENCLAW_GATEWAY_PASSWORD="your-strong-password-here"
```

### Step 5: 접속 확인

브라우저에서 `https://your-domain.com/` 접속

## 방법 C: SSH 터널 (임시 접속)

별도 설정 없이 내 PC에서 바로 접속하는 방법입니다.

### 내 PC에서 실행

```bash
# SSH 터널 생성 (로컬 18789 포트를 EC2의 18789에 연결)
ssh -i ~/Downloads/openclaw-key.pem -L 18789:localhost:18789 ubuntu@<퍼블릭-IP>
```

### 접속

터널이 연결된 상태에서 브라우저를 열고:

```
http://localhost:18789/
```

> **장점**: 추가 설치 없음, 즉시 사용 가능
> **단점**: SSH 연결을 유지해야 함, PC를 끄면 끊김

---

## 어떤 방법을 선택할까?

```
개인 사용, 간단하게 → Tailscale (방법 A)
도메인 있고, 팀/공개 서비스 → Nginx (방법 B)
지금 잠깐 테스트 → SSH 터널 (방법 C)
```
