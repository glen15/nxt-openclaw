# 01. OpenClaw 소개

## OpenClaw란?

**OpenClaw**는 오픈소스 개인 AI 어시스턴트 플랫폼입니다.

쉽게 말하면, **나만의 AI 비서를 내 서버에 설치해서 24시간 돌리는 것**입니다. ChatGPT 앱처럼 브라우저에서만 쓰는 게 아니라, WhatsApp, Telegram, Discord, Slack 같은 메신저에서 바로 대화할 수 있습니다.

### 핵심 특징

| 특징 | 설명 |
|------|------|
| **셀프 호스팅** | 내 서버에서 실행. 데이터가 외부로 나가지 않음 |
| **멀티 채널** | WhatsApp, Telegram, Discord, Slack 등 50개 이상 연결 가능 |
| **24/7 실행** | 서버에 설치하면 항상 켜져 있는 AI 비서 |
| **영구 메모리** | 이전 대화를 기억하고, 나에 대해 학습 |
| **브라우저 컨트롤** | 웹사이트를 직접 탐색하고 정보를 가져올 수 있음 |
| **스킬 확장** | 새로운 기능(스킬)을 설치하거나 직접 만들 수 있음 |

### OpenClaw가 ChatGPT와 다른 점

| 항목 | ChatGPT | OpenClaw |
|------|---------|----------|
| 실행 위치 | OpenAI 서버 | 내 서버 (EC2 등) |
| 데이터 소유 | OpenAI | 나 |
| 메신저 연동 | 제한적 | 50+ 채널 |
| 항상 실행 | 브라우저 열어야 함 | 서버에서 24/7 실행 |
| 커스터마이징 | 제한적 | 완전히 자유 (오픈소스) |
| 비용 | 월 구독료 | EC2 비용 + AI API 비용 |

## 왜 EC2에 설치하는가?

OpenClaw를 EC2에 설치하면 다음과 같은 장점이 있습니다:

1. **24시간 가동**: 내 PC를 꺼도 AI 비서가 계속 작동
2. **어디서나 접속**: 외부에서도 메신저를 통해 AI와 대화
3. **안정적 네트워크**: AWS의 안정적인 인프라 활용
4. **확장 가능**: 필요에 따라 서버 사양 변경 가능

## 시작하기 전에 필요한 것

### 필수

| 항목 | 설명 | 비용 |
|------|------|------|
| **AWS 계정** | EC2 인스턴스 생성을 위해 | 프리 티어 가능 (12개월) |
| **AI 구독** | Anthropic Claude Pro 또는 Max | 월 $20~$100 |

### 권장

| 항목 | 설명 |
|------|------|
| **Telegram 계정** | 가장 쉽게 연결할 수 있는 메신저 |
| **기본 터미널 사용법** | SSH 접속, 명령어 입력 정도 |

### 비용 예상

| 항목 | 월 예상 비용 |
|------|-------------|
| EC2 t3.medium (on-demand) | ~$30 |
| EC2 t3.medium (예약 인스턴스 1년) | ~$18 |
| Anthropic Claude Pro | $20 |
| Anthropic Claude Max | $100 |
| **합계 (최소)** | **~$38/월** |
| **합계 (권장)** | **~$50~130/월** |

> **팁**: EC2 프리 티어(t2.micro/t3.micro)는 메모리가 1GB뿐이라 OpenClaw 실행에 부족합니다. 최소 t3.small(2GB) 이상을 권장합니다.
