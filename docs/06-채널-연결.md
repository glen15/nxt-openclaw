# 06. 채널 연결 (메신저 통합)

OpenClaw의 강점은 다양한 메신저에서 AI 비서와 대화할 수 있다는 것입니다. 가장 인기 있는 3가지 채널의 연결 방법을 설명합니다.

| 채널 | 난이도 | 추천 |
|------|--------|------|
| **Telegram** | 쉬움 | 처음 시작할 때 추천 |
| Discord | 중간 | 팀/커뮤니티 사용 |
| WhatsApp | 중간 | 일상 메신저 연동 |

---

## Telegram 봇 연결 (권장, 가장 쉬움)

### Step 1: Telegram 봇 생성

1. Telegram 앱에서 **@BotFather**를 검색해서 대화를 시작합니다
2. `/newbot` 명령을 입력합니다
3. 봇 이름을 입력합니다 (예: "내 AI 비서")
4. 봇 아이디를 입력합니다 (예: `my_ai_assistant_bot`)
5. BotFather가 **봇 토큰**을 발급합니다 → 이것을 복사하세요!

봇 토큰 예시: `7123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw`

> **주의**: 봇 토큰은 비밀번호와 같습니다. 절대 공개하지 마세요!

### Step 2: OpenClaw에 봇 토큰 등록

**방법 1: CLI로 추가**
```bash
openclaw channels add --channel telegram --token "YOUR_BOT_TOKEN"
```

**방법 2: 환경변수로 설정**
```bash
echo 'export TELEGRAM_BOT_TOKEN="YOUR_BOT_TOKEN"' >> ~/.bashrc
source ~/.bashrc
```

**방법 3: 설정 파일에 직접 추가**

OpenClaw 설정 파일(`~/.openclaw/config.json5`)을 편집:
```json
{
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "YOUR_BOT_TOKEN",
      "dmPolicy": "pairing",
      "groups": {
        "*": {
          "requireMention": true
        }
      }
    }
  }
}
```

### Step 3: Gateway 재시작

```bash
# Gateway 재시작
openclaw gateway restart
```

### Step 4: 내 Telegram에서 페어링

1. Telegram에서 내가 만든 봇을 검색해서 대화를 시작합니다
2. 아무 메시지를 보냅니다 (예: "안녕")
3. 봇이 **페어링 코드**를 알려줍니다

```bash
# 페어링 코드 확인
openclaw pairing list telegram

# 페어링 승인
openclaw pairing approve telegram <코드>
```

### Step 5: 대화 시작!

페어링이 완료되면 Telegram에서 봇에게 메시지를 보내면 AI가 응답합니다.

### Telegram 추가 설정

#### 그룹 채팅에 봇 추가
1. Telegram 그룹에 봇을 추가합니다
2. 그룹에서 `@봇이름`으로 멘션하면 봇이 응답합니다

#### 프라이버시 모드 해제 (그룹에서 모든 메시지 보기)
BotFather에서:
1. `/setprivacy` 입력
2. 봇 선택
3. `Disable` 선택

> 프라이버시 모드를 변경한 후, 봇을 그룹에서 제거했다가 다시 추가해야 적용됩니다.

## Discord 봇 연결

### Step 1: Discord 봇 생성

1. [Discord Developer Portal](https://discord.com/developers/applications) 접속
2. **"New Application"** 클릭 → 이름 입력 (예: "OpenClaw Bot")
3. 왼쪽 메뉴에서 **"Bot"** 클릭
4. **"Reset Token"** 클릭 → 봇 토큰을 복사

### Step 2: 봇 권한 설정

같은 "Bot" 페이지에서 **Privileged Gateway Intents** 활성화:

- [x] **Message Content Intent** (필수)
- [x] **Server Members Intent** (권장)

### Step 3: 서버에 봇 초대

1. 왼쪽 메뉴에서 **"OAuth2"** → **"URL Generator"** 클릭
2. Scopes: `bot`, `applications.commands` 체크
3. Bot Permissions:
   - View Channels
   - Send Messages
   - Read Message History
   - Embed Links
   - Attach Files
4. 생성된 URL을 브라우저에서 열고, 봇을 초대할 서버 선택

### Step 4: OpenClaw에 등록

```bash
openclaw channels add --channel discord --token "YOUR_DISCORD_BOT_TOKEN"
```

또는 설정 파일:
```json
{
  "channels": {
    "discord": {
      "enabled": true,
      "token": "YOUR_DISCORD_BOT_TOKEN"
    }
  }
}
```

### Step 5: Gateway 재시작 및 페어링

```bash
openclaw gateway restart

# DM으로 봇에게 메시지 → 페어링 코드 확인
openclaw pairing list discord
openclaw pairing approve discord <코드>
```

## WhatsApp 연결

> **참고**: WhatsApp 연결은 비공식 라이브러리(Baileys)를 사용합니다. 계정 차단 위험이 있으니 개인 번호가 아닌 별도 번호를 사용하는 것을 권장합니다.

### Step 1: WhatsApp 채널 설정

```bash
openclaw channels login
```

터미널에 QR 코드가 표시됩니다.

### Step 2: QR 코드 스캔

1. 휴대폰에서 WhatsApp 열기
2. 설정 → 연결된 기기 → 기기 연결
3. 터미널의 QR 코드를 스캔

### Step 3: 대화 시작

WhatsApp에서 연결된 번호로 메시지를 보내면 AI가 응답합니다.

> **팁**: WhatsApp 연결은 세션이 만료될 수 있습니다. 주기적으로 `openclaw channels status`로 상태를 확인하세요.

---

## 채널 상태 확인

```bash
# 모든 채널 상태 확인
openclaw channels status

# 상세 진단
openclaw channels status --probe
```

출력 예시:
```
Channel     Status    Notes
telegram    active    Bot @my_ai_bot, 1 paired user
discord     active    Bot OpenClaw Bot, 1 guild
whatsapp    active    Connected, 2 paired users
```

## 연결 문제 해결

| 문제 | 해결 방법 |
|------|----------|
| 봇이 응답하지 않음 | `openclaw gateway status`로 게이트웨이 확인 |
| 페어링 코드가 안 보임 | `openclaw pairing list <채널>` 확인 |
| 그룹에서 응답 안 함 | 멘션으로 호출하거나 프라이버시 모드 해제 |
| WhatsApp QR 만료 | `openclaw channels login` 다시 실행 |
