# 07. 기본 사용법

OpenClaw가 설치되고 채널이 연결되었으니, 실제로 사용해봅시다.

## 대화하기

### Control UI에서 채팅

1. 브라우저에서 `http://localhost:18789/` 접속 (또는 외부 접속 URL)
2. 채팅 입력창에 메시지를 입력하면 AI가 응답합니다

```bash
# 대시보드 열기
openclaw dashboard
```

### CLI에서 채팅

```bash
# 단일 메시지
openclaw agent --message "오늘 날씨 어때?"

# thinking 모드 (더 깊은 추론)
openclaw agent --message "이 코드를 리뷰해줘" --thinking high

# 대화 모드 (연속 대화)
openclaw agent
```

### 메신저에서 채팅

Telegram, Discord, WhatsApp 등 연결된 메신저에서 봇에게 메시지를 보내면 됩니다.

---

## 자주 쓰는 명령어

### 채팅 명령어 (메신저에서 사용)

메신저에서 봇에게 다음 명령어를 보낼 수 있습니다:

| 명령어 | 설명 |
|--------|------|
| `/help` | 사용 가능한 명령어 목록 |
| `/reset` | 대화 기록 초기화 |
| `/model` | 현재 사용 중인 AI 모델 확인 |
| `/model claude-opus-4-6` | 모델 변경 |
| `/thinking high` | 깊은 사고 모드 활성화 |
| `/thinking off` | 일반 모드로 복귀 |
| `/verbose` | 상세 응답 모드 |

### CLI 명령어 (서버 터미널에서 사용)

| 명령어 | 설명 |
|--------|------|
| `openclaw gateway status` | Gateway 상태 확인 |
| `openclaw gateway restart` | Gateway 재시작 |
| `openclaw channels status` | 채널 연결 상태 확인 |
| `openclaw doctor` | 전체 시스템 진단 |
| `openclaw logs --follow` | 실시간 로그 보기 |
| `openclaw agent --message "..."` | CLI에서 메시지 보내기 |

## 실습 예제

### 예제 1: 일반 대화

```
나: 한국의 수도는 어디야?
AI: 한국의 수도는 서울입니다. 서울은 한반도 중서부에 위치하며...
```

### 예제 2: 파일 작업

```
나: ~/workspace에 hello.py 파일을 만들어줘. "Hello, World!"를 출력하는 코드로.
AI: 파일을 만들었습니다.
    ~/workspace/hello.py:
    print("Hello, World!")
```

> OpenClaw는 서버의 파일 시스템에 접근할 수 있습니다. 이를 통해 코드 작성, 파일 편집, 스크립트 실행 등이 가능합니다.

### 예제 3: 웹 검색 및 브라우저

```
나: 오늘 애플 주가 알려줘
AI: [브라우저를 열어 검색 중...]
    현재 애플(AAPL) 주가는 $XXX.XX입니다.
```

### 예제 4: 스킬 활용

```
나: 내일 오전 9시에 회의가 있다는 걸 알려줘
AI: 알겠습니다. 내일 오전 9시에 회의 일정을 기억하겠습니다.
    리마인더를 설정할까요?
```

## 스킬 관리

스킬은 OpenClaw의 기능을 확장하는 플러그인입니다.

### 설치된 스킬 확인

```bash
openclaw skills list
```

### 스킬 검색 및 설치

OpenClaw에는 ClawHub라는 스킬 레지스트리가 있습니다:

```
나: 날씨 스킬을 찾아줘
AI: ClawHub에서 날씨 관련 스킬을 검색했습니다:
    1. weather-forecast - 날씨 예보 조회
    설치할까요?

나: 응, 설치해
AI: weather-forecast 스킬을 설치했습니다.
```

> AI에게 직접 스킬 검색과 설치를 요청할 수 있습니다!

## 영구 메모리

OpenClaw는 대화 내용을 기억합니다.

```
# 첫 번째 대화
나: 내 이름은 민수야, 프론트엔드 개발자야.
AI: 안녕하세요 민수님! 프론트엔드 개발자시군요.

# 며칠 후 대화
나: 내 이름 기억해?
AI: 네, 민수님! 프론트엔드 개발자로 기억하고 있습니다.
```

## 유용한 팁

### 1. Thinking 모드 활용

복잡한 질문에는 thinking 모드를 사용하면 더 정확한 답변을 얻을 수 있습니다:

```
/thinking high
이 알고리즘의 시간 복잡도를 분석해줘...
```

### 2. 멀티 채널 활용

같은 AI 비서가 모든 채널에서 연결되므로, 상황에 맞는 채널을 사용하세요:

- **데스크탑 작업**: Control UI (브라우저)
- **이동 중**: Telegram 모바일 앱
- **팀 협업**: Discord 서버

### 3. 세션 관리

```bash
# 현재 세션 목록
openclaw sessions list

# 세션 기록 보기
openclaw sessions history
```
