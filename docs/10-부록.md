## 유용한 명령어 모음

### OpenClaw CLI 명령어

| 명령어 | 설명 |
|--------|------|
| `openclaw onboard` | 온보딩 마법사 실행 |
| `openclaw gateway` | Gateway 포그라운드 실행 |
| `openclaw gateway status` | Gateway 상태 확인 |
| `openclaw gateway restart` | Gateway 재시작 |
| `openclaw gateway stop` | Gateway 중지 |
| `openclaw dashboard` | Control UI 열기 |
| `openclaw doctor` | 전체 시스템 진단 |
| `openclaw channels status` | 채널 상태 확인 |
| `openclaw channels status --probe` | 채널 상세 진단 |
| `openclaw channels login` | WhatsApp QR 로그인 |
| `openclaw pairing list <채널>` | 대기 중인 페어링 코드 |
| `openclaw pairing approve <채널> <코드>` | 페어링 승인 |
| `openclaw agent --message "..."` | CLI에서 메시지 보내기 |
| `openclaw agent --thinking high` | thinking 모드 대화 |
| `openclaw logs --follow` | 실시간 로그 |
| `openclaw update --channel stable` | 업데이트 |
| `openclaw usage` | API 사용량 확인 |
| `openclaw skills list` | 스킬 목록 |
| `openclaw sessions list` | 세션 목록 |
| `openclaw auth login anthropic` | Anthropic 재인증 |

## OpenClaw 설정 파일 구조

```
~/.openclaw/
├── config.json5          # 메인 설정 파일
├── workspace/            # 작업 공간
│   ├── skills/           # 설치된 스킬
│   └── ...
├── agents/               # 에이전트 데이터
│   └── <agentId>/
│       ├── sessions/     # 대화 세션
│       └── memory/       # 영구 메모리
├── logs/                 # 로그 파일
├── telegram/             # Telegram 채널 데이터
├── whatsapp/             # WhatsApp 세션 데이터
└── sandboxes/            # 샌드박스 작업 공간
```

## FAQ

### Q: GPU가 필요한가요?
**A**: 아니요. OpenClaw는 외부 AI API(Anthropic, OpenAI)를 사용하므로 GPU가 필요하지 않습니다. 가벼운 Node.js 서버만 실행합니다.

### Q: 프리 티어 EC2로 실행 가능한가요?
**A**: t2.micro(1GB RAM)는 메모리가 부족합니다. 최소 t3.small(2GB) 이상을 권장합니다.

### Q: AI 구독 없이 사용할 수 있나요?
**A**: 로컬 LLM을 연결할 수도 있지만, 성능이 크게 떨어집니다. Anthropic Claude Pro($20/월) 구독을 권장합니다.

### Q: 데이터는 안전한가요?
**A**: OpenClaw는 셀프 호스팅이므로 데이터가 내 서버에만 저장됩니다. 다만 AI 추론은 외부 API를 통하므로, 대화 내용은 AI 제공자의 서버를 거칩니다.

### Q: 여러 사람이 같이 쓸 수 있나요?
**A**: 네. 각 사용자를 페어링으로 등록하고, 별도의 세션으로 관리할 수 있습니다. 멀티 에이전트 라우팅으로 사용자별 다른 설정도 가능합니다.

### Q: 서버를 재시작하면 대화 기록이 사라지나요?
**A**: 아니요. 대화 세션과 메모리는 디스크에 저장되므로 재시작 후에도 유지됩니다.

## 이 가이드에서 사용한 용어

| 용어 | 설명 |
|------|------|
| **Gateway** | OpenClaw의 핵심 서버. 모든 채널과 도구를 관리하는 중앙 제어 플레인 |
| **채널** | Telegram, Discord, WhatsApp 등 메신저 연결 |
| **페어링** | 새로운 사용자가 봇을 사용하기 위한 인증 과정 |
| **세션** | 하나의 대화 맥락. DM, 그룹별로 별도 세션이 생성됨 |
| **스킬** | OpenClaw의 기능을 확장하는 플러그인 |
| **Control UI** | 브라우저에서 접속하는 OpenClaw 관리 화면 |
| **Tailscale** | 간편한 VPN 서비스. 기기 간 안전한 네트워크 구성 |
| **데몬** | 백그라운드에서 자동으로 실행되는 서비스 |
| **온보딩** | 초기 설정 마법사 |
