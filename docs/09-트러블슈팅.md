# 09. 트러블슈팅

자주 발생하는 문제와 해결 방법을 정리했습니다.

## 진단 도구

문제가 발생하면 먼저 다음 명령어를 실행하세요:

```bash
# 1. 전체 시스템 진단 (가장 먼저!)
openclaw doctor

# 2. Gateway 상태 확인
openclaw gateway status

# 3. 채널 상태 확인
openclaw channels status --probe

# 4. 실시간 로그 확인
openclaw logs --follow
```

## 설치 관련 문제

### Node.js 버전이 너무 낮음

**증상**: `Error: OpenClaw requires Node.js 22 or higher`

**해결**:
```bash
# nvm으로 Node.js 22 설치
nvm install 22
nvm alias default 22
node --version  # v22.x.x 확인
```

### npm install 실패

**증상**: `EACCES: permission denied` 또는 빌드 오류

**해결**:
```bash
# npm 글로벌 디렉토리 권한 문제
mkdir -p ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

# 재설치
npm install -g openclaw@latest
```

### 메모리 부족 (Out of Memory)

**증상**: `FATAL ERROR: CALL_AND_RETRY_LAST Allocation failed - JavaScript heap out of memory`

**해결**:
```bash
# 스왑 메모리 확인 및 추가
free -h
sudo fallocate -l 4G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# Node.js 메모리 제한 늘리기
export NODE_OPTIONS="--max-old-space-size=2048"
```

## Gateway 관련 문제

### Gateway가 시작되지 않음

**증상**: `Error: Gateway failed to start`

**해결 순서**:
```bash
# 1. 포트 충돌 확인
sudo lsof -i :18789

# 2. 이미 실행 중인 프로세스 종료
openclaw gateway stop

# 3. 수동으로 상세 모드로 시작
openclaw gateway --port 18789 --verbose
```

### Gateway에 접속할 수 없음

**증상**: 브라우저에서 `http://localhost:18789` 접속 불가

**확인 사항**:
```bash
# Gateway 실행 중인지 확인
openclaw gateway status

# 포트 리스닝 확인
ss -tlnp | grep 18789

# 방화벽 확인 (Ubuntu)
sudo ufw status
```

### Gateway 토큰 분실

**해결**:
```bash
# 새 대시보드 토큰 생성
openclaw dashboard --no-open
```

## 채널 관련 문제

### Telegram 봇이 응답하지 않음

**확인 순서**:
```bash
# 1. 채널 상태 확인
openclaw channels status

# 2. 로그에서 Telegram 관련 오류 확인
openclaw logs --follow

# 3. 봇 토큰 유효성 확인
curl "https://api.telegram.org/bot<YOUR_TOKEN>/getMe"
```

**흔한 원인**:
| 원인 | 해결 |
|------|------|
| 봇 토큰 잘못됨 | BotFather에서 토큰 재발급 |
| 페어링 안 됨 | `openclaw pairing approve telegram <코드>` |
| DNS 문제 | `dig api.telegram.org` 확인 |

### Discord 봇이 응답하지 않음

**확인 순서**:
```bash
openclaw channels status --probe
openclaw logs --follow
```

**흔한 원인**:
| 원인 | 해결 |
|------|------|
| Message Content Intent 비활성 | Developer Portal에서 활성화 |
| 봇 권한 부족 | OAuth URL로 재초대 |
| 페어링 안 됨 | `openclaw pairing approve discord <코드>` |

### WhatsApp 연결 끊김

**증상**: WhatsApp 세션이 만료됨

**해결**:
```bash
# 재연결
openclaw channels login

# QR 코드 스캔 후 확인
openclaw channels status
```

### 그룹 채팅에서 봇이 반응하지 않음

**Telegram**:
1. `/setprivacy` → `Disable` (BotFather에서)
2. 봇을 그룹에서 제거 후 다시 추가
3. `@봇이름`으로 멘션해서 호출

**Discord**:
1. 봇에 "View Channels" + "Read Message History" 권한 확인
2. `requireMention: true` 설정 확인 → 멘션으로 호출

## AI 모델 관련 문제

### 인증 실패

**증상**: `Error: Authentication failed` 또는 `401 Unauthorized`

**해결**:
```bash
# 인증 상태 확인
openclaw doctor

# Anthropic OAuth 재인증
openclaw auth login anthropic

# 또는 API 키 직접 설정
export ANTHROPIC_API_KEY="your-api-key"
```

### 응답이 느림

**원인 및 해결**:
| 원인 | 해결 |
|------|------|
| 네트워크 지연 | EC2 리전을 미국으로 변경 (API 서버에 가까움) |
| 모델이 무거움 | 가벼운 모델로 변경 (`/model claude-sonnet-4-5`) |
| thinking 모드 | `/thinking off`로 비활성화 |
| 컨텍스트가 너무 큼 | `/reset`으로 대화 초기화 |

### 사용량 한도 초과

**증상**: `Rate limit exceeded`

**해결**:
- Anthropic Pro → Max 업그레이드 고려
- thinking 모드 사용 빈도 줄이기
- 불필요한 긴 대화 세션 정리 (`/reset`)

## 서버 관련 문제

### 디스크 공간 부족

```bash
# 디스크 사용량 확인
df -h /

# 큰 파일 찾기
du -sh ~/.openclaw/*

# 로그 정리
find ~/.openclaw/logs -name "*.log" -mtime +7 -delete

# npm 캐시 정리
npm cache clean --force
```

### 서버 재부팅 후 Gateway 안 뜸

```bash
# systemd 서비스 상태 확인
systemctl --user status openclaw-gateway

# 서비스가 비활성이면 활성화
systemctl --user enable openclaw-gateway
systemctl --user start openclaw-gateway

# 수동 시작
openclaw gateway --port 18789
```
